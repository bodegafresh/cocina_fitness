# Fitness Meal Prep System

Sistema personal de nutrición, meal prep y seguimiento físico orientado a:

* reducción de grasa corporal,
* aumento/mantención de masa muscular,
* optimización de tiempo,
* ahorro financiero,
* automatización de alimentación semanal.

---

# Objetivo

Construir un sistema simple, repetible y sostenible para:

* marcar abdomen,
* mejorar composición corporal,
* mantener energía para trabajo y entrenamiento,
* reducir decisiones impulsivas de comida,
* minimizar gasto en delivery y comida rápida.

# Filosofía del Proyecto

Este repositorio busca tratar la alimentación como un sistema optimizable:

* meal prep semanal,
* recetas reutilizables,
* métricas medibles,
* evolución progresiva,
* automatización.

La idea es cocinar principalmente:

* sábado,
* domingo,

para minimizar tiempo de cocina durante la semana.

# Reglas Base

## Alimentación

* Alta proteína
* Déficit calórico moderado
* Verduras en cada comida
* Reducir ultraprocesados
* Reducir azúcar
* Reducir alcohol

## Cocina

* Cocinar en volumen
* Congelar porciones
* Simplificar decisiones

## Fitness

* Priorizar fuerza
* Mantener constancia
* Caminar diariamente
